### 1. Website Theme and Description

**Theme:** FAST Debating Society

**Description:** A student-focused website for the FAST Debating Society that provides information about the society, its events, team members, and membership registration.

The website uses a **cyan, orange, white, and light cyan** colour scheme to maintain a consistent and attractive design across all pages.

### 2. Pages of the Website

The website consists of the following four pages:

1. **Home:** Introduces the FAST Debating Society and explains its purpose and benefits.
2. **Events:** Displays the society's activities, debates, competitions, and upcoming events.
3. **Team:** Introduces the society's leadership team and their responsibilities.
4. **Join Us:** Provides information about membership requirements and a registration form for interested students.

All pages share a consistent navigation bar, colour scheme, styling, and footer.

### 3. AI Tools Used

**ChatGPT (OpenAI)** was used as an AI assistant during website development. It helped with generating and improving HTML and CSS code, creating website pages, troubleshooting errors, and maintaining consistency across the website.
